# Bonos de cortesía: mantenimiento preventivo gratis

Cuatro bonos (3 jurados + 1 tutor) para que prueben la plataforma con un **mantenimiento preventivo de computador de obsequio**.

## Generar
```
cd backend
npm run bonos:cortesia          # vigencia 90 días (opcional: -- --dias 60)
```
Imprime 4 códigos `AXO-XXXXXXXXXX`. Es **idempotente**: volver a ejecutarlo muestra los mismos códigos. Aparecen en *Promociones → «Bono de cortesía · Mantenimiento preventivo gratis»*. Cada código es de **un solo uso**, vale lo que cuesta el servicio SOP-001 y solo aplica a ese servicio.

## Cómo lo canjea cada invitado
1. Entra a la URL de la plataforma → **Crear cuenta**.
2. *Beneficios* → escribe su código para reclamarlo.
3. Crea una solicitud con «Mantenimiento de computadores».
4. Cuando el administrador envía la cotización, la abre y aplica el código: el descuento cubre el servicio hasta el valor del bono (si el administrador cotizó el servicio por más, la diferencia se paga).

## Mensaje de invitación (copie y reemplace los datos)
> Hola, [Nombre]. Te invito a conocer **AXORA SOLUTIONS**, mi plataforma de soporte tecnológico, redes y cámaras. Como obsequio tienes **un mantenimiento preventivo gratis**.
> 1) Entra a [URL] y crea tu cuenta. 2) En «Beneficios» ingresa tu código: **[CÓDIGO]**. 3) Solicita el servicio «Mantenimiento de computadores» y aplica el código en la cotización.
> Tu código es personal y de un solo uso. ¡Gracias por participar y por tus comentarios!

Entregue cada código por un canal privado. Los códigos no son contraseñas, pero quien los tenga puede usarlos.
